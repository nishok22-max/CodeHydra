# CodeHydra / HeatLens Showcase

An interactive showcase web application highlighting urban heat vulnerability, climate intelligence, and data-to-decision workflows. Built with React, GSAP animations, Tailwind CSS v4, and Vite.

## ✨ Features

- **Interactive Climate Visualizations**: Dynamic heat risk layers, hotspot indicators, and perspective toggles.
- **Scroll-Driven GSAP Animations**: Smooth transitions, staggered reveals, and responsive interactions.
- **Tailwind CSS v4 Styling**: Modern utility-first styling with responsive, accessible layout design.
- **Production Optimized**: Fast Vite build with standalone relative asset paths for effortless deployment anywhere.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Animations**: [GSAP](https://gsap.com/) + `@gsap/react` + ScrollTrigger
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/nishok22-max/CodeHydra.git

# Enter project directory
cd CodeHydra

# Install dependencies
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build

```bash
npm run build
npm run preview
```

## 🌐 Deployment

The application uses relative paths (`base: './'`), making it deployable to any static host:
- **GitHub Pages**
- **Vercel**
- **Netlify**
- **Cloudflare Pages**
